## Intro to Python

### 1. Setup:

1.1. Option A) (Recommended) Install UV and it will install/manage Python and its dependencies:

- Windows:  

```ps
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex" 
```

- Linux/Mac:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

    1.1. Option B) (Basic) Just install Python:
        - Install Python from the official website: https://www.python.org/downloads/.  
        - Verify installation by running `python --version` in your terminal or command prompt.  

    1.2. Install a code editor like VSCode or PyCharm for writing Python code:  
        - [VSCode](https://code.visualstudio.com/)
        - [PyCharm](https://www.jetbrains.com/pycharm/)
