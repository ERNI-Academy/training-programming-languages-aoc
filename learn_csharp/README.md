## Intro to C#

1. Setup:

    - Install .NET 10 SDK from the official website: https://dotnet.microsoft.com/en-us/download
    - Verify installation by running `dotnet --version` in your terminal or command prompt.
    - Install a code editor like VSCode or Visual Studio for writing C# code: 
      - [VSCode](https://code.visualstudio.com/)
      - [Visual Studio](https://visualstudio.microsoft.com/downloads/)
    - VSCode is more lightweight and would be the recommended starting IDE, install the 'C# Dev Kit' extension

2. Free resources to learn C#:

    - https://dotnet.microsoft.com/en-us/learntocode
    - https://learn.microsoft.com/en-us/training/paths/build-dotnet-applications-csharp/
    - https://www.youtube.com/playlist?list=PLdo4fOcmZ0oULFjxrOagaERVAMbmG20Xe
    - https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/tutorials/

3. Advent of Code 2024 day 1:

    https://adventofcode.com/2024/day/1

    The input files are different for each Advent of Code user, an example can be found in the Input folder. You will need to add your own input data when solving the challenges.

    Since .NET 10, you can run a standalone .cs file directly from the terminal, without the need to create a project file or a Main method: https://devblogs.microsoft.com/dotnet/announcing-dotnet-run-app/

    In order to run the first day challenge, open the terminal, go to the learn_csharp folder path and execute `dotnet run Aoc2024Day01.cs`
